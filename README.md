# Project S'mores: a no-drill Toyota Sienna camper

A camper conversion for the 4th-generation Toyota Sienna (2021 on), built in the
open. Three lift-out plywood panels on legs carry the bed, an EcoFlow battery
drawer, a 12 V compressor fridge and a slide-out camp kitchen. Nothing is drilled
into the van.

- **The build plan (PDF, a working draft):**
  [`Project_Smores.pdf`](Project_Smores.pdf), also on the site at
  <https://smoresoutdoors.life/project-smores/>
- **Build log, photos and the parts list with real prices:**
  <https://smoresoutdoors.life/project-smores/>

The plan is still changing as the van gets built. Grab a fresh copy before you
buy or cut anything.

## Built this? Found a mistake?

Corrections from people who actually build it are the most useful thing this
plan can get. No git needed:

- **[Report a correction](../../issues/new?template=correction.yml)**: a
  dimension, part or step that's wrong.
- **[Tell us how your build went](../../issues/new?template=built-it.yml)**: what
  fit in your van, what didn't, what you'd change. Photos welcome.
- **[Ask a question](../../issues/new?template=question.yml)**

Each one needs a free GitHub account. If you don't have one, use the
[contact form on the site](https://smoresoutdoors.life/contact.html) instead.

If you're comfortable editing the text yourself, see
[CONTRIBUTING.md](CONTRIBUTING.md).

## What's in here

| File | What it is |
|---|---|
| `sienna_camper_build_plan.md` | **The plan itself.** Edit this one. |
| `Project_Smores.pdf` | The plan as a PDF, generated from the `.md` file and the shop sheets |
| `*.html` (cut list, panel and drawer sheets) | The shop drawings appended to the PDF |
| `*.scad`, `params.scad`, `render.sh` | The parametric OpenSCAD model behind the renders |
| `renders/`, `photos/` | Diagrams and build photos used in the plan |
| `build_pdf.py` | Rebuilds the PDF (`python3 build_pdf.py`) |
| `build_plan.html` | Generated by `build_pdf.py`; don't edit it |
