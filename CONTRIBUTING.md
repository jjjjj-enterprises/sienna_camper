# Contributing to Project S'mores

Thanks for helping. Most useful of all are corrections from someone who built
it: a dimension that didn't fit your van, a part that's gone, a step that was
wrong or unclear.

## The easy way: open an issue

You don't need git. Pick one of the
[issue forms](../../issues/new/choose), fill it in and attach photos if you have
them. We'll fold it into the plan and credit you if you'd like.

Issues are for things that should change the plan. Questions, ideas and photos
of your own build go in [Discussions](../../discussions): **Q&A**, **Ideas**
and **Show and tell**.

## Editing the plan yourself

1. Open [`sienna_camper_build_plan.md`](sienna_camper_build_plan.md) on GitHub
   and click the pencil icon ("Edit this file"). GitHub makes your own copy
   (a fork) for you.
2. Make the change. Keep it to one fix per pull request if you can.
3. Under "Commit changes", say what you changed and **why**: what you measured,
   in which van (year and trim), or what went wrong when you followed the old
   text.
4. Click **Propose changes**, then **Create pull request**.

A few house rules:

- **Edit the `.md` file only.** `Project_Smores.pdf` and `build_plan.html` are
  generated by `build_pdf.py`, and we rebuild them after merging. Please don't
  include them in a pull request.
- **No drilling into the van.** That's the core rule of this build. Changes
  that need holes in the vehicle won't be merged, though a note on an
  alternative is welcome as an issue.
- **Measured beats estimated.** Say which numbers you measured yourself.
- **US spellings and inches**, matching the rest of the plan.
- **Photos**: put them in `photos/`, JPEG, about 1600 px on the long side, with
  location data stripped.

Cloning is optional, and slow: the history includes every version of a ~55 MB
PDF. For text changes, the GitHub web editor is easier.
